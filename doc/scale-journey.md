# 首页的逐层放大探索

先记录本次设计，再实现。用交互动画替换首页右侧静态晶格插图，不改变课程内容、实验引擎或显式发布机制。

## 视觉叙事与科学边界

五层按用户指定的顺序展开：金属构件 → 裂纹 → 晶粒 → 位错 → 原子排列。每层显示简短观察说明与典型视野量级；尺寸为概念示意，不能当成同一试样的定量显微影像。

- 构件：可辨认的金属试样，局部存在裂纹。
- 裂纹：展示真实的开口轮廓与裂尖，选择裂尖前方区域进入微结构。
- 晶粒：不规则晶粒、晶界与取向；选择一个晶粒内部。
- 位错：晶体内部的线缺陷，选择局部核心；不画成开裂空隙。
- 原子：位错核心附近的理想化二维晶格截面，显示额外半原子面终止处。它不是特定金属的定量晶格或电子轨道。

相邻画面利用相同的观察框衔接：下一层从当前选区放大到完整视野，上一层同时放大淡出。连续进度可以正向、反向及手动拖动，避免仅以文字换页表达放大。

## 交互与实现

- `src/components/ScaleJourney.tsx`：五层导航、连续进度、自动探索、暂停、前后缩放、选区点击、双语和可访问状态。
- `src/components/ScaleJourneyScenes.tsx`：确定性的SVG科学插图与每层选区，600×360坐标系；无新依赖。
- `src/theme.css`：所有新增视觉样式、颜色与响应式布局。手机完整显示交互，不沿用旧插图的隐藏规则。
- `src/App.tsx`：只替换首页插图入口。

自动探索先停留再放大，到最后一层停止，可重播。手动操作接管进度；切换语言保留进度及播放状态。离开可视区域、切到后台或卸载时暂停/清理动画；遵循减少动态效果偏好，默认暂停并采用即时层级切换。仅在运动或自动停留计时期间使用requestAnimationFrame。

## 验证与发布

浏览器检查五层图形、连续中间帧、正反向缩放、快速点击、滑块、播放/暂停/结束/重播、语言状态、减少动态效果、移出视野和390px移动布局；截图核对裂纹/晶粒/位错/原子语义。运行现有内容与数值检查、构建及受影响首页回归。保持用户作者身份；普通push不部署，完成后运行一次`npm run deploy`并核验线上资源。
