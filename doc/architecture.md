# 多尺度建模交互教材：架构与实施计划

## 产品目标

面向材料、力学、机械专业初学者，以长度和时间的对数尺度地图组织中文课程，保留英文术语。纯静态部署于 GitHub Pages；所有教学计算在浏览器本机进行，不上传用户输入，不依赖后端或付费 API。

## 信息架构

- 首页：可交互尺度地图、学习路径、五个尺度层次、11 种方法索引。
- 方法章节：直觉 → 核心假设与方程 → 交互实验 → 算法代码 → 适用边界 → 跨尺度联系 → 可核查参考资料。
- 五层与方法：电子结构（DFT、Hartree–Fock）；原子（MD、Monte Carlo）；介观（位错动力学、Kinetic Monte Carlo）；微结构（相场、多晶塑性）；连续体（本构/速率与状态方程、有限元、有限差分）。
- 附加页面：学习路线、方法比较与参考资料。所有章节提供一致的内容深度与实际可操作示例。
- 基础课程：`#/foundations` 与 `#/foundation/:id` 提供八个双语先修章节，覆盖多尺度动机、局限、误差、电子结构、轨道、成键、能带和形成能。详细计划及科学边界见 [foundations.md](foundations.md)。
- 首页逐层放大：构件 → 裂纹 → 晶粒 → 位错 → 原子，连续相机过渡、自动/手动探索、可见性暂停及减少动态效果支持。详细计划见 [scale-journey.md](scale-journey.md)。

## 实现与文件职责

- React + TypeScript + Vite，hash 路由适配 GitHub Pages 子路径与直接刷新。
- `src/content/methods.ts`：结构化课程数据，11 种方法均遵循 `Method` 接口。
- `src/simulations/`：纯 TypeScript 数值算法，无 DOM 依赖；可单独测试。
- `src/components/SimulationLab.tsx`：实验控件、Canvas 2D、Three.js 3D、参数重置、暂停、读数。小规模模型限制规模；运行采用帧预算、暂停卸载清理，避免长期阻塞浏览器。
- `src/App.tsx`：页面、导航、尺度地图与章节组合。
- `src/theme.css`：全部视觉样式与设计变量。后续改变配色、字体、布局首先只修改此文件。
- `doc/`：架构、科学模型边界、操作与发布说明。

## 科学教学原则

- 区分完整科学算法与教学简化，清楚标注无量纲单位、维度、边界条件及近似。
- 不把能级示意称为材料 DFT 求解，不把平衡 Monte Carlo 步数解释为真实时间。
- 示例包括简化自洽场、Lennard–Jones MD、Ising MC、热激活跳跃、位错运动、Allen–Cahn 相场、Schmid 定律、应力松弛、杆单元 FEM 与热扩散 FDM。
- 2D 场、曲线、粒子及可旋转 3D 图形服务于理解，提供科学读数与可修改参数。
- 展示代码对应所选模型，并提供算法来源与进一步学习资源。

## 验证

必需：TypeScript 检查、生产构建、全部 11 个数值模型的有限值/物理不变量检查、浏览器页面与交互冒烟、手机布局、静态子路径运行。
附加：截图视觉检查、无 WebGL 时降级、减少动态效果偏好、键盘操作。

## Git 与发布

保留用户提交身份（从初始提交读取），不增加 Codex/机器人 co-author。按模块提交并 push。普通开发 push 仅运行 CI，Pages job 全部跳过；专门的 `npm run deploy` 命令检查干净工作区与远程 main 一致后，以现有用户身份创建 `site: publish <SHA>` 空提交并推送 main，此标记触发一次 Pages 构建和发布。保留 `workflow_dispatch` 作为手动入口。命令只需 Git 访问，无需 GitHub API；失败时保留本地发布提交供重试。最后执行一次发布，并以实际 Actions 与页面结果验证，不伪称发布成功。

## 实施顺序

1. 先保存本架构文档与共享接口。
2. 并行完成课程、数值模型、交互实验、发布工作流；主流程实现整体界面。
3. 集成验证、修复、提交并推送。
4. 触发一次发布并验证可访问性。

## 双语与理论深化迭代

- 顶栏提供中文 / English 按钮，记住选择；切换保留当前章节、阅读标签与实验状态，更新文档语言、标题和可访问性文案。
- 中文内容保留在 methods.ts，英文完整课程在 methods.en.ts；共享 Method 类型，禁止只翻译导航而保留中文正文。
- `src/i18n.tsx` 提供 `LanguageProvider` 与 `useLanguage()`，返回 locale、setLocale、t(中文,英文)。实验中的参数、坐标、单位解释、下载字段与状态也进行本地化；不改变数值模型。
- `src/content/theory.ts` 定义 TheoryLesson 与入口 `getTheory(id,locale)`；详细理论分为电子/原子、介观/微结构、连续体三组双语数据。
- 每章增加学习目标、深入推导/变量说明、经典算例、概念图、常见误区与可展开自测。图为带完整双语说明的 SVG 科学示意，不依赖外部图片服务。
- 阅读样式仍集中在 theme.css，正文约16px、行高1.9，导航及控件至少13–14px；长理论采用单列阅读宽度，手机端保证行长与图中文字可读。
- 验证涵盖11章两种语言、持久化切换、实验连续性、图示可访问性、移动端无溢出与原有数值测试。完成后通过专门命令发布一次。

## 数学排版与递进推导

- 课程富文本统一采用 Markdown：行内公式 `$...$`，独立公式 `$$...$$`，用 react-markdown + remark-math + rehype-katex 渲染；KaTeX 字体随构建打包，不调用外部公式服务。
- 统一 `MathMarkdown` 组件用于正文、公式、符号表、算例、答案及图注。独立 `formula` 字段存不带分隔符的纯 LaTeX，用 `display` 模式渲染；符号字段同样存纯 LaTeX，用 `inlineMath` 模式渲染。代码示例保持原始源码，不参与公式转换。
- 所有11章、中英文同步迁移，禁止用运行时正则猜测公式，避免误把普通文字/单位转为数学表达式。
- 每章增加 `derivation`，含简单情形、一般/复杂情形、扩展三阶段；每阶段列明假设，以“解释→等式变换”逐步推导，并说明新增自由度或近似何时成立。
- Markdown 不解析原始 HTML，公式 trust=false；验证所有内容中的 LaTeX 可严格编译，浏览器中无原始分隔符、公式报错与页面溢出。保留 MathML 可访问表示，长公式仅在自己的容器内滚动。
