# 浏览器教学计算与验证

这些模型为理解方法服务，均在本地 JavaScript 中运行，无远程求解服务。`src/simulations/index.ts` 是统一入口；默认种子固定，可重置复现。所有控件范围经过有限值检查，单次调用限制步数。图形的 3D 视角不会增加原模型的物理维度。

| 方法         | 实际计算                                                                                         | 时间、单位、边界与限制                                                                                                                     |
| ------------ | ------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------ |
| DFT 入门     | 一个电子的归一化高斯试探密度，能量 `E(α)=3α/2−2Z√(2α/π)`，带回溯的梯度下降                       | Hartree/Bohr 原子单位，播放为变分迭代。不是 Kohn–Sham 求解器，也没有交换相关近似；用于理解密度和总能量最小化。单高斯结果高于精确氢样能量。 |
| Hartree–Fock | 两位点 Hubbard 模型，两个相反自旋电子共占最低空间轨道；2×2 Fock 矩阵解析对角化，密度混合系数0.25 | `Fii=εi+U ni/2`，`F12=−t`；能量单位t，播放为SCF迭代。受限平均场教学模型，无真实分子积分或相关能。                                          |
| MD           | 36粒子二维 Lennard–Jones，周期边界，velocity Verlet                                              | `Δt=0.002 τLJ`；势在2.5σ截断并平移。初温去除质心速度后重新缩放，无恒温器，NVE近似能量守恒。截断力不光滑，故能量存在小误差。                |
| Monte Carlo  | 32×32 Ising，周期边界，Metropolis随机单自旋翻转                                                  | 每一步1024次翻转尝试，一个sweep；无物理时间。`J=1`，温度kBT/J，外场h/J。                                                                   |
| 位错动力学   | 65节点固定两端线张力模型 `y_t=τ+Γ y_xx`                                                          | 小斜率、约化单位；`Δt=0.2Δx²/Γ`，每显示步20子步。稳态 `y=τx(1−x)/(2Γ)`。无位错反应、交滑移、长程相互作用。                                 |
| KMC          | 单空位在15×15周期方格四向随机跳跃                                                                | `r=ν exp(−Ea/kBT)`，`ν=10¹²s⁻¹`，`Δt=−ln(u)/(4r)`，晶格间距0.25nm。展示真实随机事件时钟；位移平方为单条未折回轨迹，不是统计平均MSD。       |
| 相场         | 40×40 Allen–Cahn、双阱自由能与最近邻梯度能                                                       | 周期边界，`Δx=1, Δt=.025`；`φ_t=M(κ∇²φ+φ−φ³)`。非守恒序参量，不能把它当作守恒浓度Cahn–Hilliard。                                           |
| 多晶塑性     | 36晶粒，单滑移Schmid因子，阈值判断                                                               | `m=abs(cosθ sinθ)`，`τ=mσ`；控制轴向应力/临界分切应力，单位MPa。播放为准静态加载，未求解塑性应变、硬化、晶粒协调。                         |
| 本构方程     | Maxwell应力松弛解析解                                                                            | `ε₀=.02, σ=Eε₀ exp(−t/τ)`；E以MPa、t以秒，`Δt=.04s`。选取一个线性黏弹本构范例，不等于完整速率状态摩擦模型。                                |
| FEM          | 20个一维杆单元组装全局刚度，消去Dirichlet自由度后Thomas法求解                                    | L=1m，A=10⁻⁴m²，左固定右端力。E以GPa，显示位移μm。3D棱柱仅表示轴向解，变形放大10000倍；播放为准静态加载。                                  |
| FDM          | 32×32二维热扩散显式五点格式                                                                      | 零温Dirichlet边界，高斯初始热斑，无持续热源。约化单位，`Δx=1/31, Δt=.18Δx²`，`αΔt/Δx²≤.18<.25`。                                           |

## 测试

执行 `npm test`。测试覆盖每个模型全部控件端点组合下的确定性重置与有限值，以及：

1. 高斯变分能量单调下降，收敛到解析的单高斯极小值，保持变分上界。
2. 两位点SCF电子数守恒，自洽残差收敛，等价位点占据对称。
3. Verlet动力学近似能量守恒与粒子数守恒。
4. 低温正外场Ising铁磁有序与自旋离散性。
5. 固定端点位错线收敛至解析弓出形状。
6. KMC同种子相同事件序列，升温缩短真实等待时间。
7. Allen–Cahn离散自由能下降与序参量有界。
8. Schmid阈值的无激活/部分激活情况。
9. Maxwell经过一个松弛时间后应力降至1/e。
10. 多种网格、载荷和模量下FEM解与 `u(x)=Fx/(EA)` 一致。
11. 热扩散满足最大值原理、固定边界和热量衰减，并拒绝不稳定参数。

这些检查验证实现与所声明的教学模型一致，不构成真实材料预测能力验证。
