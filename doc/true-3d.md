# 三维轨道与三维材料模型

## 问题与目标

先记录架构，再实现。用户指出现有3D多为二维结果的立体展示，希望看到真正三维的氢/铁轨道与材料模型。审查确认：氢已有解析波函数的三维概率采样，但入口默认二维且缺乏等值面与内部观察；铁只有球谐角向振幅图，没有径向概率密度。11个方法实验原本均为低维教学模型，旋转图形不会改变求解维度。

本次提供可核验的三维数据与相应交互，并把低维结果的图示如实标注。

## 轨道数据与图形

- 氢：归一化解析1s、2s、2p_x、2p_y、2p_z波函数，逐点计算ψ(x,y,z)和|ψ|²。
- 铁：五个实3d轨道及4s，采用Slater屏蔽的氢样径向模型乘球谐函数；3d的有效核电荷6.25、4s为3.75。标明孤立原子的教学近似，不称为真实Fe的HF/DFT结果或金属电子密度。
- 在真正的三维采样体内提取正/负相位等值面，另提供按概率密度采样的点云。可旋转、缩放、改变等值阈值，并移动xy/xz/yz剖切面观察内部节点；三维形状为默认入口。
- 概率、相位、阈值、径向节点与角节点分别解释。阈值是相对最大密度，不冒充“包含某个百分比电子”的概率包络。
- 核心数值与网格提取为独立纯函数，渲染与交互分离；颜色、布局、字号仍集中在src/theme.css。

## 实验求解维度

- 保留已有二维教学例子，分子动力学和相场新增独立三维模型。选择模型维度会重置实验，选择显示方式不改变计算状态。
- MD：108个FCC初始粒子、三方向周期边界、三分量力/速度/位置、速度Verlet。数密度单位σ⁻³，温度按3(N−1)自由度计算；盒长保证截断半径小于半盒长。画面显示真实空间粒子及模拟盒。
- 相场：24³体网格、六邻居三维Laplacian、非守恒Allen–Cahn演化与三方向梯度自由能。显示φ=0的真实相界等值面，并可选择不同深度的截面；不以高度代替第三个空间坐标。
- 其余低维实验的可旋转视图称为“立体图示”，同时标明二维场值高度图、平面模型或一维结果。保留低维模型的教学价值，不宣称这些模型已经变成三维求解器。

## 验证与发布

数值验证归一化、已知轨道节点、三方向概率分布、等值面球形/拓扑与非拉伸特征；MD验证xyz运动、守恒量、周期边界与密度；相场验证独立z层、z梯度响应、能量下降和数值稳定性。浏览器验证真正的旋转/剖切/阈值变化、双语、手机、降级、状态保留及卸载。检查参考来源并明确近似。完成后以用户身份提交，普通push不部署；仅通过显式npm run deploy发布并核验线上产物。
