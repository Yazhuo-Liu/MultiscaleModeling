# 教学模型与科学边界

本网站的 11 章覆盖示意图中的全部方法。尺度地图给出典型适用范围，不是方法的硬边界：DFT/HF 基态迭代没有物理时钟；平衡 MC 扫描也不是时间。FEM/FDM 可以离散多个尺度的问题，实际范围由方程、参数、网格和计算资源决定。

## 各实验真正计算的内容

| 章节 | 浏览器计算 | 单位 / 边界 | 明确未实现 |
|---|---|---|---|
| DFT | 单电子氢样原子高斯试探密度的能量最小化 | 原子单位；Z=1..3；迭代无真实时间 | Kohn–Sham、多电子交换关联、真实材料能带 |
| HF | 两位点两电子 Hubbard 限制性 Hartree–Fock，自洽占据 | 跃迁积分 t 为能量单位；固定总电子数 2 | 真实分子积分、一般基组、动态相关 |
| MD | 36 个二维 LJ 粒子，速度 Verlet，截断平移势 | 约化单位；周期边界；dt=0.002 | 真实材料势、三维运动、恒温器 |
| MC | 32×32 Ising Metropolis | J=kB=1；周期边界；一个 sweep=N² 次尝试 | 真实时间校准、精确临界参数估计 |
| DD | 固定两端线张力位错弓出，线性小斜率 PDE | 约化变量；M=1；端点 y=0 | 网络反应、Frank–Read 环发射、位错相互作用 |
| KMC | 15×15 周期方格单空位，四等价跳跃速率 | 晶格间距 0.25 nm；ν=10¹² s⁻¹；Arrhenius 速率 | 完整缺陷物理、复杂事件目录 |
| 相场 | 40×40 Allen–Cahn 双阱自由能 | 约化单位；周期边界；非守恒序参量 | Cahn–Hilliard 守恒浓度、真实相图 |
| 多晶塑性 | 36 独立取向单滑移 Schmid 启动条件 | 应力 MPa；等应力示意 | 晶粒协调、完整滑移系、硬化、CPFEM |
| 本构 | Maxwell 应力松弛解析解，ε₀=0.02 | E 为 MPa；τ 与 t 为 s | 完整塑性、摩擦速率状态律、松弛谱 |
| FEM | 20 个一维线性杆单元，组装与求解 Ku=f | L=1m；A=10⁻⁴m²；左固定右点载 | 三维实体、弯曲、接触、非线性 |
| FDM | 32×32 五点显式热扩散，初始高斯热斑 | 约化单位；零温边界；r≤0.18<0.25 | 持续热源、对流、辐射 |

## 显示与解释

- 三维显示可用于旋转、空间观察或场的高度图。MD/KMC 仍是二维运动，场高度是场值；它们不因显示模式而成为三维求解器。
- DFT 的图为径向概率 4πr²n(r)，不是径向密度本身。高斯试探函数不能精确表示氢原子基态，因此变分最小值高于精确能量 −Z²/2 Hartree。
- HF 采用一个双占据空间轨道。Hubbard 简化相互作用下的限制性 HF 具有清晰数学定义，但不能据此推断真实分子能级。
- FEM 和多晶塑性的动画为准静态加载进度，不是动力学时间。FEM 位移图使用放大倍率，以实验内说明为准。
- FDM 使用零温边界，平均温度下降是热流出造成的物理行为；不能套用周期边界的总热量守恒判断。
- 平衡 MC 需热化、统计采样与误差评估；单帧磁化不能当成精确热力学结果。
- “本构与速率状态方程”介绍一般内部状态演化，也简述 Dieterich–Ruina 摩擦状态律；可交互计算仅覆盖 Maxwell 松弛。

## 代码与参考资料

每章代码为可独立运行的 Python 3 / NumPy 教学脚本，便于复制与修改。它们展示核心算法，不承诺逐帧复现浏览器的随机种子、网格规模或完整配置。浏览器实际实现位于 `src/simulations/`。代码与实验若采用不同维度或规模，会在注释中标明；边界条件与物理解释保持一致。

章节提供原始论文 DOI、教材与开源软件官方文档。文献用于进一步学习，不代表浏览器已经实现文献中的完整方法，也不保证收费教材全文开放。出版物链接尚未全部做在线可达性确认。

## 建议教学顺序

先学 FDM 热扩散与 FEM 杆，再学 MD 和 MC 的时间/概率差异，接着学 KMC、位错和相场，最后进入晶体塑性与电子结构。也可按长度从小到大浏览。开始电子结构前补充线性代数与量子概率；开始微结构方法前补充梯度、Laplacian 和自由能。
