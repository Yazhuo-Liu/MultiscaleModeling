# 首页的逐层放大探索

先记录本次设计，再实现。用交互动画替换首页右侧静态晶格插图，不改变课程内容、实验引擎或显式发布机制。

## 视觉叙事与科学边界

五层按用户指定的顺序展开：金属构件 → 裂纹 → 晶粒 → 位错 → 原子排列。每层显示简短观察说明与典型视野量级；尺寸为概念示意，不能当成同一试样的定量显微影像。

- 构件：可辨认的金属试样，局部存在裂纹。
- 裂纹：展示真实的开口轮廓与裂尖，选择裂尖前方区域进入微结构。
- 晶粒：不规则晶粒、晶界与取向；选择一个晶粒内部。
- 位错：晶体内部的线缺陷，选择局部核心；不画成开裂空隙。
- 原子：位错核心附近的理想化二维晶格截面，显示额外半原子面终止处。它不是特定金属的定量晶格或电子轨道。

相邻画面利用相同的观察框衔接：下一层从当前选区放大到完整视野，上一层同时放大淡出。连续进度可以正向、反向及手动拖动，避免仅以文字换页表达放大。

## 交互与实现

- `src/components/ScaleJourney.tsx`：五层导航、连续进度、自动探索、暂停、前后缩放、选区点击、双语和可访问状态。
- `src/components/ScaleJourneyScenes.tsx`：确定性的SVG科学插图与每层选区，600×360坐标系；无新依赖。
- `src/theme.css`：所有新增视觉样式、颜色与响应式布局。手机完整显示交互，不沿用旧插图的隐藏规则。
- `src/App.tsx`：只替换首页插图入口。

自动探索逐层放大，再沿原路径逐层缩小，持续往返。手动操作接管进度；切换语言保留进度及播放状态。实际画面不足55%可见、切到后台或卸载时暂停/清理动画；遵循减少动态效果偏好，默认暂停并采用即时层级切换，显式播放可观看动画。仅在运动或自动停留计时期间使用requestAnimationFrame。

## 验证与发布

浏览器检查五层图形、连续中间帧、正反向缩放、快速点击、滑块、播放/暂停/循环回程、语言状态、减少动态效果、移出视野和390px移动布局；截图核对裂纹/晶粒/位错/原子语义。运行现有内容与数值检查、构建及受影响首页回归。保持用户作者身份；普通push不部署，完成后运行一次`npm run deploy`并核验线上资源。

## 连续放大体验修订

用户反馈画面缺少逐渐变大的效果。检查发现原版约15秒后永久停在原子层，观察整个卡片的20%可见性可能提前消耗播放过程；系统减少动态效果偏好还会令显式播放直接跳层。选区边框在运动时消失、1.25秒过渡及过早淡入下一张图，也削弱了运动连续感。

本次先记录修订设计，再实现：

- 默认在实际画面至少55%可见时播放；进入画面后很快开始，逐层放大到原子，再沿原路径逐层缩小，持续往返。只在端点短暂停留，保留一键暂停和手动接管。
- 每层缩放延长至3秒；相机持续跟踪原选区，保留随相机放大的SVG选区边框，下一层细节延迟显现，帮助追踪同一位置。
- 宏观构件与放大裂纹共用轮廓及上下边缘，使用同一选区变换对齐；避免淡入时出现错位的两条裂纹。往返过程的说明文字在到达目标层时切换，自动播放时关闭重复读屏播报。
- 视野尺度随连续进度作对数插值；标明概念示意，图形缩放压缩了真实尺度跨度。
- 减少动态效果仍默认静止、手动选层即时切换；显式点击“播放动画”可观看完整动画，系统偏好变更立即停止。
- 浏览器验证必须测量真实时间推进中选区的屏幕尺寸逐帧增大，验证端点平滑回程与循环、实际画面不可见时冻结，以及减少动态效果下的显式播放。保留现有双语、移动端及键盘检查。
