# 基础课程：动机、误差与电子结构

本次先记录架构，再实现内容和交互。基础课程是现有 11 种方法之前的可选学习路线，保留中英文切换、Markdown/LaTeX、浅色主题和显式发布机制。

## 内容与入口

新增 `#/foundations` 索引及 `#/foundation/:id` 八章：

1. `why-multiscale`：问题为什么需要多个尺度；从原子势能到宏观弹性。
2. `scales-and-limits`：五尺度与全部 11 种方法的假设、局限、收敛与验证。
3. `error-propagation`：数值误差、参数不确定度、模型偏差、协方差与尺度传递。
4. `electronic-structure`：波函数、电子密度、多电子相互作用、能量和力。
5. `atomic-orbitals`：量子数，H 轨道，Fe 电子层、亚层、占据和轨道角向形状。
6. `bonding`：从两原子的成键/反键态到共价键、金属键。
7. `band-structure`：周期体系、占据、带隙、直接/间接带隙及不同带隙定义。
8. `formation-energy`：参考态、形成能/凝聚能、竞争相凸包、缺陷和热力学扩展。

首页、主导航、学习路线和相关方法章节提供入口。每章有学习目标、约五个递进小节、图示、逐步推导、算例、自检、误区、关联方法和参考资料；不在产品页面加入部署或计算位置说明。

## 科学边界与交互

- 时间和长度是典型范围，不是方法的硬边界；FEM/FDM 是离散方法，不是本构规律。收敛不能证明物理模型正确。
- 误差从局部线性传播扩展到协方差与非线性。固定力、面积、长度，弹性模量同时影响刚度和位移；逐样本刚度乘位移等于外力。模型偏差单列，不当作独立随机误差。
- 氢采用无外场、固定质子的非相对论解析 1s/2s/2p；区分空间密度、径向概率和波函数相位。轨道不是运动轨迹或硬边界。
- Fe 自由中性原子采用 [Ar]3d⁶4s²，电子层 2/8/14/2。五个 d 轨道的相位角向振幅是示意，不冒充真实 Fe 径向密度、固定能级顺序或金属 Fe 的能带。
- 轨道分级为电子层 → 亚层占据 → 轨道形状；提供 2D 和可旋转缩放的 3D。按需绘制，清理资源；无 WebGL 时提供 2D 回退；语言切换保留选择及相机。
- 能带用半填充二聚化链：t₁=1 eV、t₂=0.6 eV 时带隙 0.8 eV；闭隙不一概称普通金属。真实带隙与光学/基本/KS 带隙分别说明。
- 凸包使用假想 A–AB–B 的每原子形成能 0/−0.30/0 eV；候选 A₃B 为 −0.10 eV/atom 时，相对 A+AB 混合物高 0.05 eV/atom。明确负形成能不保证稳定，绘图区分竞争相基线和加入候选后的凸包。
